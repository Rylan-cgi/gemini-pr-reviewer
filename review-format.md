# Pull Request Review Layout Template

When formatting pull request reviews, use this exact structure:

*   **Header:** `Pull Request Review: PR #<number> (bcgov/nr-ilcr)` (at the very top of the comment)
*   **Verdict:** `🚨 Review Verdict: REQUIRED CODE CHANGES` (or `✅ Review Verdict: APPROVED` if issues are resolved)
*   **Review Body:** Direct summary or structured bullet points of strengths, changes, and verification.
*   **Exclusions:** Do NOT include any "Reviewer", "Title", or "Target" metadata lines in the header block.
*   **Tone:** Professional, direct, concise, senior software engineer and collaborative peer programmer. No conversational chitchat or preambles.
